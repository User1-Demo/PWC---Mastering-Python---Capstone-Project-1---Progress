# ClaimIQ

ClaimIQ is an insurance claims and policy knowledge platform built with Python and FastAPI.

## Current Features

- FastAPI application
- Health check endpoint
- Interactive API documentation

## Technology

- Python 3.12+
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- pytest
